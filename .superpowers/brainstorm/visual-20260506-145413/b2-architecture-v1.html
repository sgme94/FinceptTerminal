原 Fincept 页面到 Polymarket 的映射
1

Dashboard -> Overview

保留 shortcuts + agent composer 结构，改为 bot health、paper/live、资金、持仓、订单队列。

2

Markets -> Polymarket Markets

把 global market cards 改为事件市场卡、概率走势、成交量、spread、liquidity、order book。

3

Agentic World -> Event Sentinels

把 sentinels 改造成政治、宏观、加密、体育、政策、链上等事件监控 agent。

4

Fund Managers -> Strategy Arena

把 fund manager leaderboard 改成策略/agent 组合排名：NAV、return、drawdown、hit rate、trade log。

保留

  • Fincept 终端黑底、等宽字体、低圆角、右侧 rail、底部状态栏。
  • 14 个入口的导航密度，但重命名为 Polymarket 运营语义。
  • Dashboard composer、Markets 密集表格、News feed、Agentic/Fund Manager 两个特色页面。

改造

  • 股票/外汇/宏观行情降级为外部参考数据，不作为核心交易对象。
  • Plans & Credits 暂时作为占位支撑页，不进入 MVP 核心。
  • 移动端按 Fincept 骨架重做触控尺寸，不照搬原站 18-26px 小按钮。
